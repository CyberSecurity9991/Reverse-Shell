# Security Policy

## Purpose

This repository contains **educational security research code** intended for use in isolated lab environments only. It is not designed, tested, or intended for use in production or against real-world systems without explicit authorization.

## Reporting a Concern

If you have any concerns about the content of this repository, or believe it violates GitHub's policies, please **open an issue** on this repository. I will respond as soon as possible.

Please do **not** use this code against any system you do not own or have permission to test.

## Responsible Use

- Use only in isolated lab environments (Host-Only network).
- Obtain written permission before testing any system.
- Follow all applicable laws and regulations.
- Report any vulnerabilities you find responsibly.

## Contact

For security-related concerns, please open an issue on this repository.
